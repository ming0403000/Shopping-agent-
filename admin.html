連線到 GitHub

第一次使用要貼上 GitHub 存取金鑰，後台才能幫你上傳照片和更新商品。金鑰只會存在這台電腦的瀏覽器裡。

怎麼取得金鑰？（只要做一次）
  1. 打開 GitHub 新增金鑰頁面（要先登入 GitHub）
  2. Token name 隨便取，例如 shop-admin；Expiration 可選 90 天或更久
  3. Repository access 選 Only select repositories，再選 Shopping-agent-
  4. Permissions → Repository permissions → 找到 Contents，改成 Read and write
  5. 拉到最下面按 Generate token，複製那串 github_pat_ 開頭的金鑰，貼到下面
